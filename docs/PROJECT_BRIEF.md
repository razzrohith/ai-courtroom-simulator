# JudgeBench Project Brief

## Overview

JudgeBench is an AI-powered courtroom simulator featuring three autonomous agents: Judge, Prosecutor (Plaintiff), and Defense. The system orchestrates a realistic legal proceeding through 12 distinct phases with structured dialogue and evidence management.

## Goal

Build a safe, modular MVP that demonstrates multi-agent courtroom simulation using mock data, establishing a foundation for future real LLM integration.

## Target Users

- Law students practicing case analysis
- Educators demonstrating legal procedures
- AI developers exploring multi-agent orchestration
- Hobbyists interested in legal technology

## Constraints

- Frontend-only (React/TypeScript/Vite/Tailwind)
- No real API keys or paid calls
- Fictional case only
- No deployment in Phase 1

## Success Criteria

1. App runs without errors
2. All 12 phases accessible via "Next Turn" button
3. Transcript shows speaker names and messages
4. Evidence board displays all evidence items
5. Verdict renders with reasoning after trial ends
6. No crashes or console errors in production build
